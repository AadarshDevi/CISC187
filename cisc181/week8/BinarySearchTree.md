## Part 1 — Is It a Binary Search Tree?

***Question:*** Are the following trees Binary Trees?
1. Tree A: ***Yes***
	```
		50
	   /  \
	 30    70
	/ \    / \
   20 40  60 80
	```

2. Tree B: ***No***
	```
		50
	   /  \
	 30    70
	   \
		60
	```

3. Tree C: ***Yes***
	```
		40
	   /  \
	 20    70
	/ \    /
   10 30  50
	```
